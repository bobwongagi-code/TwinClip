# TwinClip 重复实验复盘与修复方案

## 结论边界

本轮完成了 16 条视频、每条 5 次、共 80 个形式完整的结果文件。结果使用同一份固定参考图谱和固定证据快照，不能解释为端到端 ASR/OCR 稳定性。

更重要的限制是：worker 线程曾被复用，后续任务采用 prompt-reset continuation。因而这 80 次不是经过证明的独立同分布样本。`execution-audit.json` 记录了这个问题。报告中的重复轨迹只能作为执行上下文信号，不能直接当作模型稳定性的证据。

## 已观察到的特征

1. `S` 是主要波动来源。全体运行中 `S` 的总体标准差为 22.83、两两平均绝对差为 25.83，均高于 `L` 的 16.86 和 18.63。当前最需要校准的是 Storyboard 节点和关系的功能/元素/支撑判断，而不是先调整 `T` 的权重。
2. 证据选择不是主噪声。固定证据下，只有 `mai199_7` 的证据集合两两 Jaccard 中位数低于 0.8，说明多数波动来自同一证据的解释阈值，不是模型每次找到了完全不同的事实。
3. 教学点阈值存在明显漂移。31 个视频-教学点组合的深度在 5 次运行中发生变化，尤其集中在 REF-B 的个人体验、额外用途和机制点。
4. lane 切换发生在窄 margin。6 条视频发生主 lane 切换，相关样本的有效覆盖率 margin 中位数约为 0.071-0.125；`sifu.yusuf` 有 80% 的运行是严格并列，说明它应走明确的 tie-break，而不是让模型自由选择。
5. 档位会放大边界噪声。`ftiha.sd`、`mai199_7`、`nizzahhhhh`、`sahabanu_79_1` 的 T 分布跨越或贴近档位边界，单看档位会掩盖连续分布的差异。
6. 证据质量是独立混杂因素。固定快照中未知 ASR/OCR 通道占 50%，且本轮含有马来语/混语处理风险，不能通过放宽评分阈值解决。
7. 置信度字段没有区分度。80 次均为 `medium`，`E/M/R` 基本固定在 `1/0.5/0`，当前不能用它决定人工复核优先级。

## 修复优先级

### P0：先修实验执行层

- 每个 replicate 使用真正隔离的新进程或新 worker；prompt-reset 不再被视为独立上下文。
- 用不可变 wrapper 注入并校验 `run_id`、`video_id`、`round`、`replicate_index`；身份不匹配时禁止发布结果。
- 每个运行写入唯一临时文件，严格校验通过后再原子发布到正式路径。
- 每次记录 `model`、`prompt_version`、`temperature`、`seed`（若可用）和 `execution_context_id`。

### P1：修量表和 lane 判断

- 对 31 个不稳定教学点分别补充 0/1、1/2、2/3 的正反对照样本，明确最低证据门槛和 `primary_failure_dimension`。
- Storyboard 的 `function_score`、`element_score`、`support_score` 要求每一项都绑定证据和简短判据；优先校准 S，不先改 `T=0.70L+0.30S`。
- lane 选择固定为“有效覆盖率 → T → 声明顺序”，同时输出两 lane 的覆盖率、T 和 margin。margin 小于预设阈值时标记人工复核，不允许只看主 lane。
- `T`、档位和区间全部由确定性代码根据未四舍五入的 L/S 重算，模型只提供原子判断。
- 置信度必须从证据完整度、lane margin、档位边界距离、语言质量和人工复核比例计算；如果组件不变，禁止默认输出 `medium`。

### P2：修证据与语言层

- 只统计评估中实际挂载的 `evidence_ids`，不能把完整固定证据库当作已选证据。
- 对 `mai199_7` 这类证据集合发生漂移的样本，先修证据链接和盲提取，再判断语义阈值是否需要调整。
- 马来语/Manglish 的 ASR、OCR 和人工复核单独做质量实验；未知通道不进入“模型判断稳定性”的归因。

## 修复后验收

当前尚未完成修复后的二次验证，不能声称稳定性已经提升。下一轮应使用未参与规则调整的留出视频，且满足：

- 100% 运行身份、上下文标识和固定证据 hash 校验通过。
- 100% `T=0.70L+0.30S` 公式残差通过，档位由代码重算。
- 每条视频同时报告 T/L/S 的中位数、极差、总体标准差、平均绝对偏差、两两平均绝对差、档位切换率、lane 切换率、lane margin 和逐点深度分布。
- 比较修复前后分布是否收窄、档位/lane 切换是否减少、锚点排序是否保持；不以均值是否更高或更低作为改进标准。
- 对真正隔离上下文后的精确重复率单独报告，不能与当前混合上下文结果直接比较。
